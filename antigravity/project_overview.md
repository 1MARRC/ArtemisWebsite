# Project Overview

## What is Flywall?
Flywall is a "second you" desktop application built for knowledge workers (founders, product managers, consultants). It captures meetings, documents, notes, and research, then organizes them into a private local memory board. 

**Core Value Proposition:**
- **100% On-Device:** Audio transcription, summarization, and AI chat happen locally. No data leaves the device.
- **No Cloud / No Account:** Privacy by design.
- **Local AI Recall:** Users can ask questions about their meetings or documents, and a local model answers using their private knowledge base.
- **No Lock-in:** All data is exportable as Markdown with YAML frontmatter.

## What is this Website?
This project (`flywall-website`) is the **marketing and beta-distribution website** for the Flywall desktop app. 

It is designed to "wow" the user with a dynamic, highly interactive frontend that explains the product's pillars, highlights its privacy-first nature, and manages a closed beta access system.
