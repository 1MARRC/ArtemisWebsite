# Project Glossary

- **Flywall:** The core product. A desktop application that acts as a local-only AI memory for meetings, notes, documents, and research.
- **Second you / Second self:** The primary marketing term for Flywall's AI, emphasizing that it remembers everything you learn and answers questions based on your data.
- **Beta Gate:** The mechanism on the `download.html` page that prevents unauthorized users from downloading the application binaries. It requires a valid beta key.
- **Tweaks Panel:** An internal developer/design tool overlaid on the site. It allows live adjustments to CSS variables and copy strings to quickly test design variations in the browser.
- **Netlify Functions:** Serverless Node.js endpoints hosted by Netlify. Used in this project for beta key validation (`validate-key.js`).
