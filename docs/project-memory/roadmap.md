# Roadmap

## Planned Features
- **Public Launch Transition:** Remove the beta gate from `download.html` when the product reaches General Availability. Update the main page copy to reflect public availability.
- **Dynamic Installer Links:** Update the placeholder `#` links in `download.html` and the `flywall-release.js` file with actual CDN URLs when binaries are ready.

## Prioritized Backlog
1. Finalize the exact production URLs for the macOS, Windows, and Linux installers.
2. Update `flywall-release.js` with the correct `FLYWALL_RELEASE_VERSION` and sizes.
3. Process incoming beta requests from Netlify Forms and generate/distribute keys.

## Milestones
- [x] Initial website launch (marketing copy + animations).
- [x] Closed Beta gate implementation.
- [ ] First active beta binaries distributed.
- [ ] Public Launch (Beta gate removed).

## Future Enhancements
- Expanded interactive mockups in the hero section.
- Integration of actual product screenshots once the UI is finalized.

## Deferred Work
- Establishing an automated email pipeline for beta keys (currently a manual process).
